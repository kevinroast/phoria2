Phoria

pho·ri·a (fôr-)

n. The relative directions of the eyes during binocular fixation on a given object

    What's all this then? - phoria is a JavaScript library for simple 3D graphics on a canvas 2D context. It does not use WebGL, so it runs anywhere an HTML5 canvas does. phoria2 is a modern rewrite of the original 2013 library - ES modules, Vite, and the same friendly API. Vector and matrix maths by gl-matrix.
