Phoria

pho·ri·a (fôr-)

n. The relative directions of the eyes during binocular fixation on a given object

phoria2 is a small, fast, Open Source JavaScript library for 3D on the web: a WebGL 2 renderer with PBR materials, instancing, points, lines, labels, picking and particles. An API small enough to learn in an afternoon. No runtime dependencies, ES modules, and validation messages that tell you (or your coding agent) what to write. It is a rewrite of phoria, a library from 2013 that rendered 3D on a 2D canvas context.
