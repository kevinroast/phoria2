Phoria

pho·ri·a (fôr-)

n. The relative directions of the eyes during binocular fixation on a given object

What's all this then? phoria2 is a small JavaScript library for 3D on the web: a WebGL 2 renderer with PBR materials, instancing, points, lines, labels, picking and particles, behind an API small enough to learn in an afternoon. It is a rewrite of phoria, a 2013 library that drew 3D with the canvas 2D context - no runtime dependencies, ES modules, and validation messages that tell you (or your coding agent) what to write instead.
